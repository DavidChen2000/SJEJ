# SJEJ 閱讀器

**線上閱讀：** https://davidchen2000.github.io/SJEJ/

《SJEJ 閱讀器》是一個以正體中文閱讀《屬靈的判定與判定的實例》內容的網頁閱讀器，整理全書共七十篇文章，適合在電腦或手機瀏覽器使用。

## 功能

- 瀏覽七十篇目並閱讀文章
- 搜尋文章標題、經文或內容；手機開啟文章後會以本文搜尋標示關鍵字並前往第一個命中處
- 桌面版可用 Ctrl+F／Command+F 搜尋本文；從全站搜尋結果進入時會自動帶入關鍵字
- 手機長按文章可使用原生選字選單，並可開啟本文搜尋逐筆查看符合文字
- 收藏文章至書籤
- 調整文章字體大小與切換閱讀主題
- 朗讀文章時會嘗試保持手機螢幕喚醒；暫停、結束或停止朗讀時釋放
- 記錄閱讀進度，方便接續閱讀
- 支援安裝至裝置主畫面，並快取已載入內容供離線瀏覽
